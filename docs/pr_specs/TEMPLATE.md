# PR title

Copy this template to a new file to explain a PR or hand off an upcoming one. Keep each section short.

## Meta

| Field | Value |
| --- | --- |
| Status | `need triage` |
| PR | Pending, or link to the related PR |

Use one status. `need triage` means decisions are still open. `ready` means the scope is agreed and implementation can start. `implemented` means the PR contains the described change.

## Goal

State the outcome in one or two sentences.

## Non-goals

List the scope boundaries that matter to the reviewer or next contributor.

## Outline

Summarize the main changes in a few bullets. For a handoff, include open decisions and the next step. For an implemented change, include how it was verified if useful for review.
